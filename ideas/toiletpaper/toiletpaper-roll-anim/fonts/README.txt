Drop the TT Moons .otf files in here.

css/styles.css looks for these names:

    TT_Moons_Trial_Regular.otf     (or "TT Moons Trial Regular.otf")
    TT_Moons_Trial_Medium.otf      (or ..._DemiBold.otf)
    TT_Moons_Trial_Bold.otf        (or "TT Moons Trial Bold.otf")

If the files are absent the page falls back to Playfair Display, loaded from
Google Fonts, which is close enough to review the layout with.
